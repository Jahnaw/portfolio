## Run locally

Requirements: Node.js 20.9 or newer.

```bash
git clone https://github.com/Jahnaw/jahnawi-portfolio.git
cd jahnawi-portfolio
npm install
npm run dev
```

Open http://localhost:3000.

The portfolio content is centralised in `src/config/portfolio.ts`. The page layout and visual sections live in `src/app` and `src/components`.
